# Правила репозитория trade-setups-scanner

## Инвентаризация серверных изменений

При внесении изменений на сервер, на котором разворачивается приложение,
необходимо пополнять документацию по инвентаризации в `docs/invent/`.
Каждый сервер имеет отдельный файл `<имя-сервера>.md` с перечнем всех
изменений: установленные пакеты, созданные файлы и директории, конфигурация
сервисов, сетевые порты, маршруты и т.д.

**Важно:** каталог `docs/invent/` добавлен в `.gitignore` и не попадает
в удалённый репозиторий. Это позволяет хранить детали конкретной
инфраструктуры (IP-адреса, имена хостов, пути, порты) только в локальной
копии, не раскрывая их публично.
